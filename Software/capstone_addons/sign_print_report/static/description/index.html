Digital Signature | Sign Print Report | Sign any Report

This module allows users of Odoo to Place Coordinates on any model and select a report or upload a PDF file. Users can include their name, phone number, email address, company name, and signature.

Digital Signature | Sign Print Report | Sign any Report



Features

- Sign any print report
- Upload new report from local disk
- Drag and Drop Coordinates
- Upload / draw / load signature
- Download the signature from popup



Installation

- Copy sign_print_report module to addons folder

- Install the module normally like other modules

1. Open any record

Eg. Sales --> Orders - > Quotations -> Open a Record -> Form View -> Click on the Sign Icon




2. Select Report / Upload PDF File

Sign Print Report Popup -> Select Option





Place Coordinates





Sign Report





Double Click on the Sign Block to Upload new Signature
